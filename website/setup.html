Setup

Changeover does the deciding — which disc, which film, which part of it, where the file goes. The actual reading and encoding is done by tools you install yourself. This page explains why, and gives you the commands.

Why the tools aren't included

Ripping a DVD means decrypting it, and the libraries that do that (libdvdcss and friends) sit in a legal grey area that differs by country. Distributing them inside a signed, notarized app would mean shipping decryption software to everyone who downloads it, in every jurisdiction, and taking responsibility for that. I'm not willing to do that, and you shouldn't want an app that does it quietly.

HandBrake is also licensed under the GPL. Bundling it inside a closed application raises licensing questions I'd rather not answer badly.

So Changeover ships with none of it. You install the tools, from their own projects, under your own account — the same as if you used them from Terminal. Changeover finds them and calls them. That keeps the decision, and the copy of the software, with you.

None of this is legal advice. Whether you may rip a disc you own is a question for where you live, not for this page.

Homebrew

Homebrew is the package manager most Mac developers use to install command-line software. If you haven't used it, its home page has a one-line installer and an explanation of what it does.

Install Homebrew first, if you don't already have it:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

That command comes from brew.sh — check it there rather than trusting this page.

What Changeover needs

Required

Without this, nothing can be ripped:

brew install handbrake

This installs HandBrakeCLI, which scans the disc and encodes the movie. Changeover looks for it at /opt/homebrew/bin/HandBrakeCLI; if yours is elsewhere, set the path in Settings.

Recommended

Everything below is optional. Changeover works without each one — it just does less. Settings ▸ Dependencies shows which are present and what each is for. 

brew install lsdvd
brew install ffmpeg
brew install libdvdread
brew install libdvdcss
ToolWhat it addsWithout it
lsdvd Reads the disc's own identifier, so your choices survive taking a disc out and putting it back. Discs are identified by their label instead, which is nearly always fine.
ffmpeg Renders one still per disc menu so the text on it can be read, and upgrades an existing import's metadata. No menu text, so no chapter names and fewer hints about the film.
libdvdread
libdvdcss		 Decrypt menu video so the menus can be looked at. Menu buttons and their targets are still read; the pictures are not.

All four at once, if you'd rather:

brew install handbrake lsdvd ffmpeg libdvdread libdvdcss

Optional fallback

For a disc HandBrake cannot read, Changeover can hand off to MakeMKV. It is not used otherwise, and most discs never need it. 

brew install --cask makemkv

On-device intelligence

Changeover uses two Apple frameworks to work out what a disc is. Both run entirely on your Mac. Nothing about your discs is sent to Apple, to me, or to anyone else.

Vision — reading the words on a disc's menus

After scanning, Changeover renders each of the disc's menu screens to an image and uses Vision's text recognition on it. That is how it finds chapter names, which languages a disc offers, and sometimes the film's own title printed on the main menu — information a DVD holds as pictures rather than as text, so there is no other way to get at it.

Apple Intelligence — making sense of what was read

Most discs spell their title in the volume label with the spaces removed: THESECRETLIFEOFWALTERMITTY. Changeover asks Apple's on-device language model to put the spaces back, and — when the label says nothing useful — to work out which film the menu text is describing.

It never decides what gets ripped. The title, the tracks and the file name come from the disc scan and from you, and anything it fills in is shown before ripping starts so you can change it.

Turning it off

In Settings ▸ Disc Recognition:

  • Use Apple Intelligence to help identify discs — off means the model is never asked. Changeover falls back to the disc label and the menu text as they are. Takes effect on the next disc; no relaunch needed.
  • Pick the matching movie automatically — off means you always choose from the search results yourself.
  • Start ripping on its own when the disc is recognised — off means nothing starts without you pressing Start.

Vision's text recognition is part of reading the menus and is skipped entirely if ffmpeg isn't installed — so not installing it is the way to opt out of that half.

Apple Intelligence needs a Mac that supports it and has it enabled in System Settings. Where it isn't available Changeover carries on without it.

Checking your setup

Open Settings ▸ Dependencies. Every tool is listed with whether it was found, what it is for, and the exact command that installs it if it is missing.
