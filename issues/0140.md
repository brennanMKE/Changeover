# 0140 — The window grows with the disc's content until Start Ripping is off-screen

| | |
|---|---|
| **Status** | open |
| **Phase** | 3 — Unattended multi-disc |
| **Module** | MetadataEntryView / DiscTitleListView / TrackSelectionView |
| **Platform** | macOS |
| **First seen** | 2026-09-16 |

## Description

On *The Girl in the Spider's Web* (2026-09-16, joe) the metadata window became unusable: the feature title carries **7 audio tracks and 21 subtitle tracks**, every subtitle is listed as its own row ("English · bitmap — cannot become an MP4 track", 21 times), and the window grew past the screen. The user could not reach `Start Ripping` at all.

Every section in the window lays itself out at full natural height — the search results, the title table, the audio list, the subtitle list and the log — so a disc with a lot of tracks pushes the action bar off the bottom. The subtitle list is the worst offender and is **purely informational**: Phase 2 output carries no subtitles (#0036), so 21 rows of "cannot become an MP4 track" are spending the user's screen on nothing.

## Expected behavior

The action bar is always reachable, on any disc, at any window size. Long lists scroll or collapse inside the window rather than growing it.

## Plan

- Give the window a layout that pins `Start Ripping` (and the Start decision caption from #0053) to the bottom, always visible, and lets the middle scroll.
- Collapse the subtitle list behind a disclosure summarising it ("21 subtitle tracks, none carried into the output"), collapsed by default. It is reference-only until #0036.
- Cap the sections that can grow without bound — search results, the title table, the audio list — with their own scroll areas and sensible maximum heights, rather than one outer scroll view that makes the whole window a long strip.
- Keep the log pane's existing behaviour (#0043's `displayLines`); it is already bounded.
- Check the window's minimum size still shows: the confirmation row, the Start button and its reason, and some log.
- Test the pure parts: a summary-line helper for the collapsed subtitle disclosure belongs in `DiscTitleFormatting` with unit tests. The layout itself is manually verified on joe — no UI tests (CLAUDE.md).
