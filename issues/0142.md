## Resolution notes

> 🟢 Resolved — the rip window is one step at a time, derived and never stored (`FlowStep`), with the disc scan as a single line (`ScanStatusLine`), a real HandBrake progress bar and ETA (`HandBrakeProgressParser` → `JobProgress`), and the encoder log moved out to the History window. Specified in `docs/ux-step-flow.md`.

## Description

The rip window put everything on one screen — metadata entry, the title list, track selection, and a live encoder log — so the one thing the user had to decide next was never obvious, and the only progress signal was HandBrake's own chatter scrolling past.

The window now shows exactly one of five steps (Insert disc → Choose movie → Confirm → Ripping → Done), chosen by a pure function over the current state. Progress is a parsed percentage and ETA rather than log text, and the log lives in History, which is also the only place it lives.
