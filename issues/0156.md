# 0156 — A colon in a title becomes `-` with no space before it

## Description

The path sanitizer from #0010 replaces `:` with `-` character-for-character, so
`Hellboy II: The Golden Army` becomes:

```
Hellboy II- The Golden Army (2008) {tmdb-11253}
```

There is no space before the hyphen, which reads as a typo rather than as
punctuation. `Hellboy II - The Golden Army` is what a person would write.

Cosmetic only — Plex matches on the `{tmdb-ID}` tag, so nothing is mismatched
or lost.

## Suggested fix

Replace `": "` with `" - "` before falling back to replacing a bare `:` with
`-`. The two-step order matters: a colon with no following space (rare, but
possible in a title) should still become a plain hyphen.

## The part that needs a decision

Roughly 113 folders already in the user's library were named under the current
rule. Changing the sanitizer alone makes new imports disagree with old ones for
the same kind of title, which is arguably worse than the current consistent
wart.

So this is really two questions, and the second is the user's:

1. Should the sanitizer change? (Yes — it is a clear improvement.)
2. Should existing folders be renamed to match? Renaming is safe for Plex,
   which keys on the tmdb tag, but it touches the user's library and should not
   happen without them asking for it.

Do not land 1 without an answer to 2.
