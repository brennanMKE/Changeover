# 0244 — A menu button that dispatches cannot be tied to a title

|---|---|

## Description

On many discs a menu button does not `JumpTT` to a title. It jumps to another
PGC which then decides, by comparing a register against a table of constants,
which title to play. The app follows the button one hop, finds a PGC rather than
a title, and stops — so the label on screen can never be attached to the thing
it plays.

The consequence is small-sounding and is not: every bonus feature on such a disc
arrives unnamed, and a title the menu reaches may be dropped entirely (#0230).

This ticket exists because #0230 was filed "blocked on the dispatch resolver"
and **the resolver had no ticket**. Four discs now show the shape and the thing
they are all waiting on was not written down anywhere.

## The shape, measured on four discs

All traces from the agent session driving joe, 2026-09 to 2026-10.

**SEVENTH_SON** — buttons set `g4`; `vtsm-05 pgc8` `JumpSS`es to `vmgm pgc6`,
which compares `g4` against constants and `JumpTT`s.

**OBLIVION** — the same shape, with a fuller table:

| `g4` | title |
|---|---|
| 2 / 3 / 4 | 6 / 3 / 7 (Destiny, Illusion, Harmony) |
| 0xb–0xf | 9–13 (deleted scenes Play All, Bubbleship Flyby, Stadium, Medkit, The Archives) |
| anything else | **5** (the fallback) |

**PACIFIC_RIM_UPRISING** — a *different* encoding of the same idea. Each pair is
`00b1 0009 VVVV LLLL` (if `g9 != V`, goto line `L`) followed by `JumpTT`.
`g9=0x1f` → title 26 — a title the scan does not even list, because the
minimum-duration filter dropped it (#0230).

**FLETCH** — `vtsm-01-lu1-pgc12` has four bonus labels (Making / Disguises /
Favorite Moments / Trailer) and **all four target `menu:1.pgc5`**. Five short
titles, four labels, and nothing to pair them with.

## Why this is tractable

It is a bounded dispatch table, not computation. Following the launcher PGC and
collecting the `(constant → title)` pairs gives the button-to-title map without
executing anything. Two encodings are known (compare-and-jump on `g4`,
not-equal-goto on `g9`) and both are small.

## What must not be got wrong

**The fallback arm.** OBLIVION's table falls through to title 5, and on a disc
where the fallback *is* the feature a resolver that collects only the explicit
pairs picks the wrong title and looks confident doing it. The fallback is part
of the table, not a default to ignore.

**Titles the scan never listed.** PACIFIC_RIM_UPRISING dispatches to title 26,
which the duration floor removed before anything could ask. So the resolver and
#0230 have to land together: resolving a map to a title that was already
discarded helps nobody.

## Relation

Blocks #0230. Related to #0241 only in that both are about the app knowing
something it cannot say.

## Notes

2026-10-07, and the others were not captured either. The evidence is the decoded
