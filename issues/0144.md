## Resolution notes

> 🟢 Resolved — the minimum-length floor now applies to HandBrake's own `mainFeatureIndex`, not just to the app's fallback guess. A scanner answer that names a title too short to be a feature is discarded like any other bad candidate.

## Description

Reported on a real disc: "It marked 13 as the main feature. That appears to be only 2:26." HandBrake's `MainFeature` flag was accepted unconditionally, so a disc where the flag lands on a trailer or a menu loop would have been ripped as the feature — and with automatic ripping on, filed under the film's name.

The length floor that already protected the fallback heuristic was extended to cover the scanner's answer, so both paths are held to the same standard.
