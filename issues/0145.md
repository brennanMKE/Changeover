## Resolution notes

> 🟢 Resolved — `widescreenPreferred` drops the 4:3 twin when a disc carries the same feature at two aspect ratios, so the widescreen transfer wins.

## Description

Flipper and dual-side discs carry the feature twice: once widescreen, once pan-and-scan at 4:3. Both titles have the same runtime and chapter count, so nothing in the length-based heuristic distinguished them and the pan-and-scan version could be picked — a permanently cropped library copy.

Aspect ratio now breaks that tie.
